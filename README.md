# Varg Medical Platform

A full medical platform built using:

- FastAPI Backend
- Next.js Frontend
- Tailwind CSS
- Gemini 2.5 Flash AI
- Supabase Database

## Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
